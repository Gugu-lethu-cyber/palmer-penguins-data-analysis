# Palmer Penguins Data Analysis

## Project Overview
This project analyses physical measurements of three penguin species from Antarctica using Python.

## Research Questions
- Which species has the highest average body mass?
- Which species has the longest average flippers?
- Is there a relationship between flipper length and body mass?

## Dataset
The dataset contains Adelie, Chinstrap and Gentoo penguins.

Source: https://github.com/allisonhorst/palmerpenguins

## Tools Used
- Python
- Google Colab
- Pandas
- Matplotlib

## Data Cleaning
Missing physical measurements were removed.
Records with missing sex information were retained.

## Key Finding
The correlation between flipper length and body mass was 0.871,
indicating a strong positive relationship.
